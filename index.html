How the math works

    
Three draw models, scored differently

    
States don't all run the same system — using the wrong formula on the wrong state is the single biggest mistake a planning tool can make. Hunter applies the model that actually governs each state's draw.

    

      

        
Preference points

        
Tags go to the highest point-holders first, working down until the quota is filled. If your points clear last year's published cutoff for a unit, you're in strong shape for the 1st-choice round. Below it, your real chance comes from leftover or later-choice rounds. Used by Colorado, Wyoming, California, Oklahoma, and others.

      

      

        
Bonus points

        
Each point buys one extra entry in a weighted random drawing — never a guarantee. A first-time applicant can still beat someone holding ten points; the odds just tilt further in the point-holder's favor each year. Used by Arizona, Nevada (with a squared formula), Utah, Oregon, and others.

      

      

        
Pure lottery

        
No points exist. Every valid application has identical odds, every year, regardless of history. Used by Alaska, Idaho, New Mexico, Iowa, Kansas, and others.
